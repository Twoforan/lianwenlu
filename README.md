# 炼文炉

一款把 **AI 对话（Chatbox 式体验）深度集成进码字软件** 的安卓写作应用。

写正文的地方直接挂着 AI 助手；选几章正文、几段大纲，一键塞进上下文；AI 生成的人设、世界观、故事线可以直接**解析并写回大纲库**。作者不用在「写作软件」和「AI 聊天工具」之间来回搬运文本。

- 纯本地存储（Room + DataStore），不依赖任何后端
- 兼容 OpenAI Chat Completions / Responses 两类接口，DeepSeek、Kimi、GPT、Claude 等均可接入
- **长期记忆**：把本书已写正文向量化，写新章节时自动检索相关片段作为参考资料（支持厂商 Embedding API 或本地离线模型）
- **内置《炼文炉 · 使用说明书》**：首次启动自动生成在书架上，覆盖全部功能，可阅读 / 导出，也可作为 AI 上下文书籍直接提问用法；随 App 版本自动更新
- 当前版本：**v4.4.9**（versionCode 64，minSdk 26 / targetSdk 35），安装包见 [Releases](https://github.com/Twoforan/lianwenlu/releases/latest)

## 功能总览

### 书架与书籍管理

- 新建 / 编辑书籍：自定义封面（可选图片，未选时淡纯色 + 书名兜底）、书名、简介、所属分组（可现场新建分组）
- 分卷 / 章节标题前缀自定义：`%n` 阿拉伯数字、`%N` 中文数字（如 `第%n卷`、`第%n章`）
- 列表 / 图墙两种展示模式；按时间或名称排序，支持倒序
- 书籍分组：创建分组、移动分组、按分组筛选
- 书籍操作：编辑、置顶、预览、分享、**复制本书**（新建空白书并完整复制原书大纲，新书名自动加 （1）（2）… 序号，原书的常驻化分类、自定义分类与字段模板一并迁移）、删除、批量管理（可取消 / 全选 / 返回键退出）
- 导出：整本合并为单个 txt / Word（txt 含分卷标题），或按章节分别导出（按分卷子目录组织）

### 章节编辑

- 每章包含 **标题、梗概、正文** 三部分，即时自动保存
- **一键排版**：首行缩进两字符，可配置行间距、左右边距、底部边距、排版空行
- **样式**：字号、字体、加粗 / 斜体 / 居中对齐、字体颜色、背景颜色
- **智能标点**：成对标点自动补全、冒号紧随双引号
- **快速定位**：记住上次退出时编辑位置，回来直接继续
- **查看**：查找替换、全书查找、字数统计、粘贴、全选
- **工具箱**：
  - 分享章节：生成图片 / txt / Word
  - 人名生成、地名生成、AI 人名 / 地名生成
  - 保持屏幕常亮
- 目录侧栏：新建章节 / 分卷，长按删除、拖拽任意排序，正序 / 倒序切换；默认展开上次编辑章节所属分卷，其余收起
- 章节长按菜单：「**批量管理**」入口，支持多选、拖拽排序、批量移动分卷、批量删除、批量合并成章、一键重排章节序号
- 章节长按菜单：标题支持就地改名，改完自动写回书籍
- 书籍导出：整本合并导出，或**导出所选章节**为单个 txt（按选择顺序，章节标题作分隔）
- 编辑页右侧抽屉：不离开编辑器即可唤起完整 AI 对话；AI 回答支持一键 **「写入当前章节」**（把回答覆盖写入本章正文并自动一键排版，正文非空时先弹窗确认）；抽屉头部标题为「**AI**」，下方一行显示**当前所在章节**并支持**长按改名**（改名同步更新抽屉头部、编辑器标题栏与书本目录）；抽屉底部还有 **「跳转本卷下一章节」**，本卷有下一章直接跳过去，到卷末则自动在本卷新建一章再跳过去并保持抽屉打开
- 侧边抽屉底部快捷按钮行（**一屏正好容纳，无需左右滑动**）包含 **「＋本章梗概」「快捷提示词」「梗概 + 发送」「正文 + 发送」「发送」** 五项，其中「生成梗概」「生成正文」让 AI 直接按本章设定产出草稿（详见下方「生成梗概 / 生成正文」）

### 作品大纲

- 大纲按 **标签分类** 组织：故事大纲、人设、世界观、灵感库……分类可自由增删
- 每条大纲 = 显示标签 + 结构化字段（字段名 / 字段值），字段模板按分类记忆
- 长按标签可编辑 / 删除，也可 **常驻化**（再次点击取消）：已常驻的分类标签前显示一枚图钉图标
- 配合前缀词管理里的 **适配性筛选**，常驻分类的大纲可固定作为首轮上下文（该开关同样作用于「生成正文」时的参考资料注入）
- 大纲导入规则：同一标签下**名称一致的条目覆盖替换**，新条目**追加到该标签末尾**

### AI 对话（核心）

把 Chatbox 搬进了码字软件，并且围绕写作场景做了大量上下文工程：

**上下文选择**

- 一键勾选书籍（单选，分组筛选 + 搜索）、大纲条目（按标签筛选 + 搜索，支持 **全部大纲 / 常驻大纲 / 普通大纲** 筛选，「全选」按当前筛选范围生效）
- **「上下文 / 大纲」展开面板重做**：抽屉底部点「上下文」「大纲」弹出的面板已按新设计稿重排——白卡外观 + 圆形图标抬头（「选择上下文 · 已选 N 章」/「选择大纲 · 已选 N 项」）+ 筛选药丸（上下文为 全选 / 梗概 / 正文，大纲为 全部 / 常驻 / 普通）+ 分组行（展开箭头 + 勾选框 + 名称 + 已选计数）与条目行；按钮本身只保留文字，展开时淡紫底高亮
- **章节「逐章独立勾选」**：面板顶部有 **全选 / 梗概 / 正文** 三个按钮，分别一键全选（或再次点击取消）所有章节的梗概与正文、所有章节的梗概、所有章节的正文；下方列表按「章节 / 梗概 / 正文」两列复选框展示（章节名旁不再有独立勾选框），**勾选某章的梗概或正文即自动把该章纳入上下文**，两列都取消才移出，可单独勾选任意分卷或任意章节，精确控制注入粒度、省 token
- **「搜索中 / 生成中」冒泡提示**：工具栏正上方（对话区底部居中）会出现一枚白色小药丸——记忆检索进行中显示「搜索中」，生成梗概 / 生成正文期间显示「生成中」，不再占用「下一章」旁的一行提示
- **统一「跟书走」**：AI 上下文一律绑定整本书，不再区分跟书走 / 跟章节走
- 会话列表支持按 **分组 / 书籍（含「未绑定」分类）/ 分卷 / 章节** 筛选，可搜索会话标题
- **会话换绑书籍**：长按会话可修改名称或**切换绑定书籍**；换绑弹窗提供「历史对话」「历史预设」两个勾选项（勾「历史对话」把原有历史带入新书上下文，勾「历史预设」把此前导入的大纲与章节梗概保留进新书预设，两项全选即整段搬运到新书并自动解除原章节映射）
- 文件清单：随会话生成，可复制，方便粘贴到网页版继续讨论

**前缀词管理（设置 → 通用设置）**

- 上下文前缀化（默认开启）、大纲前缀化（默认开启）、自定义纯文本前缀
- **首轮全选大纲**：开关（设置项已从「通用设置」移入本页）；开启后新建跟书会话首轮全选大纲，发送后自动取消勾选
- **首轮全选章节**：独立开关（默认开启）；开启后新建跟书会话首轮全选章节（梗概全选、正文不选），发送后自动取消勾选；关闭则新建会话不默认勾选章节
- **适配性筛选**（默认关闭）：开启后首轮「全选大纲」只全选 **常驻化分类** 下的全部内容；之后每轮发送提示词时，用**本章梗概**精准匹配 **非常驻化分类** 下各条目的显示标签，命中的条目把其下完整字段（表）作为「新增大纲资料」在检索片段之后、提示词之前交给 AI，已命中过的不重复提交，只有新命中 / 新增的才追加，显著减少无关大纲占用上下文。关闭则保持原样（首轮全选全部大纲）
- **适配性筛选的作用范围已扩展**：该开关此前只影响普通聊天发送；现在开启后，**「生成正文」时同样生效**——用本章梗概匹配非常驻化分类下各条目的显示标签，命中的条目以「新增大纲资料」并入本次正文的参考资料。触发条件只需该开关本身开启

**省 token 与缓存优化**

- **首轮全选大纲**：跟书模式下仅首轮注入大纲前缀，后续轮次复用，显著提高 prompt cache 命中率
- 上下文前缀在多轮间保持稳定，最大化命中供应商侧缓存
- 会话展示 **缓存命中率**（cached tokens / prompt tokens），每轮可见省了多少
- 已适配 GPT、Claude 的缓存机制（效果欢迎反馈）

**对话体验**

- 流式输出，思考过程（reasoning）单独展示；生成中与生成完成使用**同一张卡片外壳**（淡紫底、圆角描边、操作栏与正文同结构），不再出现生成前后两种样式
- **按章节断点折叠**：会话自动按章节分组，每一组都带章节抬头、可整组收起（含最后一章）；历史章节默认收起（收起时显示章节名、「共 N 条对话 · 约 N 字」与一行内容预览），当前章节默认展开；长按分组标题的章节名可**就地改名**并同步写回书籍目录；章节被删除后该分组仍可**长按重命名**（删除即解除映射，改名只作用于该组）
- **分组卡片「头 — 对话 — 尾」**：展开时底部有一条带 ∧ 的收起条，点卡片头部或底部收起条都能把整块向上收起；卡片无外描边，对话区、尾条与头部等宽
- **未绑定章节的对话按「一轮对话」成块**：标题显示为「第 X 轮对话」，长按可改本轮名称（只改这里，不会同步到书籍章节）
- **打开即定位**：展开编辑器侧边 AI 时自动滑动到绑定章节的对话分组并展开、其余分组收起；导航栏 AI 或未绑定章节的侧边 AI 打开时自动滑到最后一轮对话末端
- 消息抬头精简：用户消息与 AI 回答都不再显示时间与「分卷 · 章节名」，只保留正文与操作栏
- **功能栏「查看日志」与「查看本轮提示词」**：查看日志弹窗标题为「**提交日志**」，以可折叠的三级结构（预设日志 / 上下文日志 / 本轮提示词日志）展示每次请求发了什么，其中「预设提示词」为模型配置里实际生效的系统提示词；查看本轮提示词只回显本轮实际发送的内容（本章梗概、检索片段、新增大纲、用户提示词）
- 长对话自动定位到该看的位置，不会每次回到开头
- 长按选中复制，点击别处取消选中
- 消息支持编辑重发、删除、回复引用
- **重新生成不堆积上下文**：同一轮提问多次「重新生成」只把**当前生效的那一版**回答送进后续请求的历史，废弃候选不会并列堆积（避免提示词 token 膨胀）
- 常用提示词库：标题 + 内容，一键插入输入框
- 输入区统一为「圆角描边卡片 + 内嵌无边框输入框」；导航栏 AI 聊天页在输入框内保留圆形发送按钮，编辑器侧边抽屉的输入框不设发送按钮（发送改由底部快捷按钮行承担）

**生成梗概 / 生成正文（章节编辑页侧边抽屉）**

侧边 AI 抽屉底部快捷按钮行里的 **「生成梗概」「生成正文」** 两个入口（该行共五项，一屏正好容纳、无需左右滑动）：

- **生成梗概**：按本章上下文与（可选）指定的大纲条目撰写本章梗概，生成结果**只输出梗概正文这一整段文字**，不会附带核心事件清单、步骤说明、字数统计等多余内容；单独点它时，聊天区会显示这次生成对应的**用户提示词与 AI 回复**，该回复的操作栏带 **「写入梗概」** 图标，点一下即可把这条梗概写回本章
- **生成正文**：按本章梗概、会话前缀里的大纲设定与（可选）记忆检索片段撰写正文；结果作为一条普通 AI 回答进入当前会话，由用户在编辑器里点 **「写入当前章节」** 决定是否落笔（**不自动写入**）
- 生成正文**不新增用户消息**，只在会话里追加一条 AI 回答供你决定是否写入正文；生成正文且同时生成梗概时，梗概内容保持隐形、不占用对话展示
- 生成请求与普通聊天**复用同一段前缀结构**（模型预设 + 自定义前缀 + 工具块 + 参考资料前缀），供应商侧前缀缓存可在聊天与生成之间共享命中；开启「生成工具携带本会话历史消息」后，历史对话以「**前情提要**」参考资料块（`用户：… / 助手：…`）随请求发出，**不再作为对话轮次**，模型因此不会把上一章成品误当成正在续写的内容；该块会**按章节分段并在每段前标注章节名**（如「第3章」「第4章X」），生成梗概与生成正文两条路径一致；生成指令还会点明「现在撰写的是『本章标题』」
- 输入框（提示词栏）里写的文字会作为生成请求的**最后一条用户消息**一同发出，因此其中写的情节要求会生效；该输入在生成后不会被清空。开启「同时生成梗概」时，这段输入会被发送两次（梗概子调用一次、正文一次）
- **弹窗一次性弹干净**：点「生成正文」时，所有需要用户决策的弹窗（先「选择大纲」，再「是否启用记忆检索」）会在**进入执行前按固定顺序依次弹完**，执行阶段不再弹任何需要输入的选择框；**任一弹窗取消即整体终止**，不会发出任何生成请求。两个弹窗均已按新设计稿重排为全宽圆角卡片（选择大纲带搜索框与分类药丸，记忆检索带淡紫说明块与「关闭 / 开启」按钮）
- **生成进行中**：工具栏正上方会出现「生成中」冒泡小药丸，底部操作栏同时给出「停止」按钮，可随时中止
- **生成时贴底跟随、不打断阅读**：逐步输出到达时只做一次平滑贴底补滚，不再来回跳动；只有你正停在对话底部时才跟随最新输出，向上翻看前文时列表保持当前位置
- **生成结束不跳末尾**：回答写入后不会再把视图拉到对话末尾，自动定位只在刚进入本章节 / 会话时执行一次，你停在哪里就一直留在哪里
- **长时间无输出自动中止**：流式请求连续 3 分钟没有有效输出（服务端只发心跳保活也算无输出）会自动中止并提示，不会永久停在「生成中」；生成中重复点击也会提示先点「停止」
- **新开对话 / 切换会话会终止在途生成**：点「＋」新建对话、切换会话或删除当前会话前，会取消上一会话仍在执行的生成梗概 / 生成正文 / 流式回答，并复位「生成中」、流式回显与待确认弹窗，避免新会话残留生成态
- **梗概子调用失败显式三选一**：开「同时生成梗概」时梗概若生成失败，会弹「重试 / 使用已有梗概 / 取消」，避免出现「梗概为空却已写出正文」

**生成设置（设置 → AI工具 → 生成设置）**

- **字数区间**：梗概 0–500 字、正文 0–6000 字，**双滑块**；下限拉到 0 表示不约束下限。超出上限时自动截断到最后一个完整句子并提示；低于下限只提示、不重试
- **「限定梗概范围」**开关（默认关闭）：开启后点「生成梗概」先弹**大纲条目多选**（可按分类筛选、全选 / 取消），只按选中设定生成；若标签已在会话上下文中，只写「参见大纲『X』」而不再重复提交内容
- **「记忆检索」三态**（开启 / 关闭 / 询问，**默认询问**）：生成正文前是否按本章梗概检索本书已写正文片段作为参考资料；检索段数沿用长期记忆里的区块设置。询问模式下点「取消」会**终止整个生成流程**
- **「生成正文的同时生成梗概」**开关（默认关闭）：开启后先生成梗概并静默写入本章梗概，再据此生成正文；关闭时若本章没有梗概会提示先填写

**AI 工具（可插拔）**

设置 → 通用设置 → **AI 工具**，目前内置两个工具（可同时启用；工具卡片**默认全部收起**，点卡片标题才展开对应配置），下方另有 **「生成设置」** 子页（设置 → AI工具 → 生成设置，集中配置「生成梗概」「生成正文」的字数区间、限定梗概范围、记忆检索三态与「同时生成梗概」，页面已按新设计稿重排，详见上方「生成设置」）：

「**写入大纲工具**」

- **复制工具定义**：一键复制该工具的 JSON Schema 定义（工具名 / 说明 / 参数结构）与旧版标记格式兼容说明，粘贴给任何支持自定义工具的 AI
- **粘贴导入大纲**：粘贴含 `<<<AI_OUTLINE_JSON_V1>>>` 标记的文本会直接解析；粘贴自由文本会调用当前模型自动提取后再写入。按标签归位写入指定书籍的大纲库（无标签则新建；同标签下同名条目覆盖替换）
- 在 AI 聊天页勾选后：AI 在合适时通过**工具调用**回传结构化内容（回答仍是自然语言），应用自动弹出导入预览，可逐条勾选、换书（可现场新建）后一键入库，同名条目会在预览里标注「将覆盖同名条目」

「**批量写入章节梗概**」

- **复制工具定义**：一键复制 `import_chapters` 工具定义与旧版 `<<<AI_CHAPTER_JSON_V1>>>` 标记说明
- **粘贴导入章节梗概**：粘贴含标记的文本直接解析；粘贴自由文本会调用当前模型自动提取后再写入。按分卷归位批量创建章节并写入梗概；分卷不存在自动创建，卷内已有同名章节则覆盖梗概
- 聊天页同样可勾选启用，工具被调用时同样弹出导入预览

工具走主流接口的**原生工具调用**（Chat Completions / Responses / Anthropic 均已适配，流式与一次性返回都支持），旧标记格式继续兼容。模型不支持工具调用时会自动重试一次不带 tools 的请求，并在回答操作栏提供「导入」按钮做二次解析。两个工具可同时勾选；一次回答里解析出多组内容时**逐个弹窗确认**。未选书时会弹选书窗口（含完整新建书籍表单：封面 / 简介 / 分组）。工具协议开放，后续会持续增加新工具。

**长期记忆（书本向量化 / 记忆检索）**

把本书**已写正文**向量化存入本机，写新章节时自动翻出「和本章梗概最相关」的旧正文片段，作为参考资料随提示词一起交给写文模型（向量工具只负责检索，结果不会直接返回给你）。

- 开启方式：设置 → 通用设置 → **长期记忆**；开启后在 AI 侧边栏 / 对话页勾选「记忆检索」
- **向量化工具二选一**：
  - 厂商 Embedding API：填 BaseURL / API Key / 模型，随时可换
  - **本地向量化工具**：内置 llama.cpp（arm64-v8a），需先下载 `BGE small zh v1.5`（约 15MB）与 `BGE reranker base`（约 209MB）两个模型，支持断点续传；两个模型全部就绪后方可启用，向量化与检索全程离线
- **检索链路**：先按余弦粗召回 Top20，再用重排模型精排到目标区块数；本地工具走 BGE reranker，厂商 API 无重排时等价纯余弦
- **记忆检索区块设置**：区块配额 5-20、检索范围偏好（随机匹配 / 最新章节优先 / 最早章节优先），可在此子页配置
- **检索范围与配额**：自动排除「当前正在写的这一章」，且同一章最多取 2 块，避免参考资料全挤在一章
- **删除章节同步清理向量**：删除章节（含批量删除、合并章节、删除整本书）会一并清除该章节的全部向量块；检索阶段再按「现存章节」过滤，已删章节的内容绝不会进入参考资料
- **向量化进度**：按「全部书籍 / 各分组 / 未分组」查看筛选
- **增量向量化**：正文改动会自动重跑对应章节；切换向量化工具 / 模型会整本重跑（不同工具产出的向量不在同一向量空间）；未重新向量化时会明确提示
- **检索片段去重**：与「适配性筛选」的大纲资料采用同一套去重机制——已在本会话提交过的检索片段不再重复注入（去重键是片段文本的短哈希，存在会话前缀里、只增不减）；换绑书籍时会重置去重键

### AI 配置

- **供应商管理**：名称、BaseURL、API Key、接口类型（Chat Completions / Responses），支持快捷添加常见供应商
- **模型管理**：从供应商自动拉取可选模型列表，按模型配置温度、最大输出 token
- **思考模式**：每个模型可单独设置是否开启思考/推理，以及思考强度档位（低 / 中 / 高 / 极，默认开启且取最高强度）；按模型自动映射到各后端原生参数（OpenAI / DeepSeek 的 `reasoning_effort`、Claude 的 `thinking.budget_tokens`、千问的 `chat_template_kwargs`、智谱 / 豆包的 `thinking.type` 等），超出模型支持范围时自动夹取到可用最大值；未识别的模型不发送任何思考参数
- **预设提示词**：系统级 prompt 配置
- **上下文不限**：可关闭上下文长度限制

### 使用说明书（内置）

## AI 大纲导入格式

「写入大纲工具」使用如下固定格式（复制提示词后 AI 会自动遵循）：

```text
<<<AI_OUTLINE_JSON_V1>>>
{
  "blocks": [
    {
      "type": "标签",
      "name": "显示名称",
      "fields": [
        {"key": "字段名", "value": "字段值"}
      ]
    }
  ]
}
<<<END_AI_OUTLINE_JSON_V1>>>
```

- `type`：所属大类（人设 / 世界观 / 故事线……），无则新建标签
- `name`：条目显示名，同标签下重名自动加序号
- `fields`：条目字段；字段值含引号或换行需按 JSON 规则转义

## AI 章节梗概导入格式

「批量写入章节梗概」走原生工具调用 `import_chapters`，工具参数结构如下：

```json
{
  "chapters": [
    {
      "volume": "分卷名，没有可写空字符串",
      "chapterName": "章节名",
      "summary": "章节梗概",
      "order": "章节在本卷的序列号"
    }
  ]
}
```

旧版标记文本仍可解析（粘贴导入或回答里出现都支持）：

```text
<<<AI_CHAPTER_JSON_V1>>>
{ "chapters": [ { "volume": "", "chapterName": "章节名", "summary": "章节梗概", "order": 1 } ] }
<<<END_AI_CHAPTER_JSON_V1>>>
```

- `volume`：分卷名；为空则写入第一卷，分卷不存在则自动创建
- `chapterName`：章节名；卷内已有同名章节则打开该章（写入而非新建）
- `summary`：章节梗概；该章已有梗概则覆盖
- `order`：章节在本卷的序列号（新章节按顺序追加）
