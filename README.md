# 炼文炉

一款把 **AI 对话（Chatbox 式体验）深度集成进码字软件** 的安卓写作应用。

写正文的地方直接挂着 AI 助手；选几章正文、几段大纲，一键塞进上下文；AI 生成的人设、世界观、故事线可以直接**解析并写回大纲库**。作者不用在「写作软件」和「AI 聊天工具」之间来回搬运文本。

- 纯本地存储（Room + DataStore），不依赖任何后端
- 兼容 OpenAI Chat Completions / Responses 两类接口，DeepSeek、Kimi、GPT、Claude 等均可接入
- **长期记忆**：把本书已写正文向量化，写新章节时自动检索相关片段作为参考资料（支持厂商 Embedding API 或本地离线模型）
- **内置《炼文炉 · 使用说明书》**：首次启动自动生成在书架上，覆盖全部功能，可阅读 / 导出，也可作为 AI 上下文书籍直接提问用法；随 App 版本自动更新
- 当前版本：**v3.3.0**（versionCode 44，minSdk 26 / targetSdk 35），安装包见 [Releases](https://github.com/Twoforan/lianwenlu/releases/latest)

## 功能总览

### 书架与书籍管理

- 新建 / 编辑书籍：自定义封面（可选图片，未选时淡纯色 + 书名兜底）、书名、简介、所属分组（可现场新建分组）
- 分卷 / 章节标题前缀自定义：`%n` 阿拉伯数字、`%N` 中文数字（如 `第%n卷`、`第%n章`）
- 列表 / 图墙两种展示模式；按时间或名称排序，支持倒序
- 书籍分组：创建分组、移动分组、按分组筛选
- 书籍操作：编辑、置顶、预览、分享、**复制本书**（新建空白书并完整复制原书大纲，新书名自动加 （1）（2）… 序号，原书的常驻化分类、自定义分类与字段模板一并迁移）、删除、批量管理（可取消 / 全选 / 返回键退出）
- 导出：整本合并为单个 txt / Word（txt 含分卷标题），或按章节分别导出（按分卷子目录组织）

### 章节编辑

- 每章包含 **标题、梗概、正文** 三部分，即时自动保存
- **一键排版**：首行缩进两字符，可配置行间距、左右边距、底部边距、排版空行
- **样式**：字号、字体、加粗 / 斜体 / 居中对齐、字体颜色、背景颜色
- **智能标点**：成对标点自动补全、冒号紧随双引号
- **快速定位**：记住上次退出时编辑位置，回来直接继续
- **查看**：查找替换、全书查找、字数统计、粘贴、全选
- **工具箱**：
  - 分享章节：生成图片 / txt / Word
  - 人名生成、地名生成、AI 人名 / 地名生成
  - 保持屏幕常亮
- 目录侧栏：新建章节 / 分卷，长按删除、拖拽任意排序，正序 / 倒序切换；默认展开上次编辑章节所属分卷，其余收起
- 章节长按菜单：「**批量管理**」入口，支持多选、拖拽排序、批量移动分卷、批量删除、批量合并成章、一键重排章节序号
- 章节长按菜单：标题支持就地改名，改完自动写回书籍
- 书籍导出：整本合并导出，或**导出所选章节**为单个 txt（按选择顺序，章节标题作分隔）
- 编辑页右侧抽屉：不离开编辑器即可唤起完整 AI 对话；AI 回答支持一键 **「写入本章正文」**（把回答覆盖写入本章正文并自动一键排版，正文非空时先弹窗确认）；抽屉里还可直接 **新建章节**，新建后自动跳转新章节并打开抽屉

### 作品大纲

- 大纲按 **标签分类** 组织：人设、世界观、故事线（明线 / 暗线）、灵感库……分类可自由增删
- 每条大纲 = 显示标签 + 结构化字段（字段名 / 字段值），字段模板按分类记忆
- 长按标签可编辑 / 删除，也可 **常驻化**（再次点击取消）：已常驻的分类标签前显示一枚图钉图标
- 配合前缀词管理里的 **适配性筛选**，常驻分类的大纲可固定作为首轮上下文
- 大纲导入规则：同一标签下**名称一致的条目覆盖替换**，新条目**追加到该标签末尾**

### AI 对话（核心）

把 Chatbox 搬进了码字软件，并且围绕写作场景做了大量上下文工程：

**上下文选择**

- 一键勾选书籍（单选，分组筛选 + 搜索）、大纲条目（按标签筛选 + 搜索，支持 **全部大纲 / 常驻大纲 / 普通大纲** 筛选，「全选」按当前筛选范围生效）
- **章节「逐章独立勾选」**：面板顶部有 **全选 / 梗概 / 正文** 三个按钮，分别一键全选（或再次点击取消）所有章节、所有章节的梗概、所有章节的正文；下方列表按「章节 / 梗概 / 正文」三列复选框展示，可单独勾选任意分卷或任意章节的梗概与正文，精确控制注入粒度、省 token
- **统一「跟书走」**：AI 上下文一律绑定整本书，不再区分跟书走 / 跟章节走
- 会话列表支持按 **分组 / 书籍（含「未绑定」分类）/ 分卷 / 章节** 筛选，可搜索会话标题
- 文件清单：随会话生成，可复制，方便粘贴到网页版继续讨论

**前缀词管理（设置 → 通用设置）**

- 上下文前缀化（默认开启）、大纲前缀化（默认开启）、自定义纯文本前缀
- **首轮全选大纲与章节**：开关（设置项已从「通用设置」移入本页）
- **适配性筛选**（默认关闭）：开启后首轮「全选大纲」只全选 **常驻化分类** 下的全部内容；之后每轮发送提示词时，用**本章梗概**精准匹配 **非常驻化分类** 下各条目的显示标签，命中的条目把其下完整字段（表）作为「新增大纲资料」在检索片段之后、提示词之前交给 AI，已命中过的不重复提交，只有新命中 / 新增的才追加，显著减少无关大纲占用上下文。关闭则保持原样（首轮全选全部大纲）

**省 token 与缓存优化**

- **首轮全选大纲**：跟书模式下仅首轮注入大纲前缀，后续轮次复用，显著提高 prompt cache 命中率
- 上下文前缀在多轮间保持稳定，最大化命中供应商侧缓存
- 会话展示 **缓存命中率**（cached tokens / prompt tokens），每轮可见省了多少
- 已适配 GPT、Claude 的缓存机制（效果欢迎反馈）

**对话体验**

- 流式输出，思考过程（reasoning）单独展示；生成中与生成完成使用**同一张卡片外壳**（淡紫底、圆角描边、操作栏与正文同结构），不再出现生成前后两种样式
- **按章节断点折叠**：会话自动按章节分组，历史章节整组包裹并默认收起（收起时显示章节名、「共 N 条对话 · 约 N 字」与一行内容预览），当前最新章节直接展开；长按分组标题的章节名可**就地改名**并同步写回书籍目录
- **分组卡片「头 — 对话 — 尾」**：展开时底部有一条带 ∧ 的收起条，点卡片头部或底部收起条都能把整块向上收起；卡片无外描边，对话区、尾条与头部等宽
- **未绑定章节的对话按「一轮对话」成块**：标题显示为「第 X 轮对话」，长按可改本轮名称（只改这里，不会同步到书籍章节）
- **打开即定位**：展开编辑器侧边 AI 时自动滑动到绑定章节的对话分组并展开、其余分组收起；导航栏 AI 或未绑定章节的侧边 AI 打开时自动滑到最后一轮对话末端
- 消息抬头精简：用户消息与 AI 回答都不再显示时间与「分卷 · 章节名」，只保留正文与操作栏
- **功能栏「查看日志」与「查看本轮提示词」**：查看日志弹窗标题为「**提交日志**」，以可折叠的三级结构（预设日志 / 上下文日志 / 本轮提示词日志）展示每次请求发了什么，其中「预设提示词」为模型配置里实际生效的系统提示词；查看本轮提示词只回显本轮实际发送的内容（本章梗概、检索片段、新增大纲、用户提示词）
- 长对话自动定位到该看的位置，不会每次回到开头
- 长按选中复制，点击别处取消选中
- 消息支持编辑重发、删除、回复引用
- 常用提示词库：标题 + 内容，一键插入输入框
- 输入区统一为「圆角描边卡片 + 内嵌无边框输入框 + 圆形发送按钮」，主聊天页与编辑器右侧抽屉样式一致

**AI 工具（可插拔）**

设置 → 通用设置 → **AI 工具**，目前内置两个工具：

「**写入大纲工具**」

- **复制工具提示词**：一键复制固定格式说明，粘贴给任何 AI 使用
- **导入大纲**：粘贴含 `<<<AI_OUTLINE_JSON_V1>>>` 标记的文本，自动解析并按标签归位写入指定书籍的大纲库（无标签则新建，重名自动加序号）
- 在 AI 聊天页勾选「写入大纲工具」后：AI 生成人设 / 世界观时按固定格式输出，回答完毕自动询问是否写入大纲，选书（可现场新建）后一键入库

「**章节梗概导入工具**」

- **复制工具提示词**：一键复制 `<<<AI_CHAPTER_JSON_V1>>>` 格式说明
- **导入章节梗概**：粘贴含标记的文本，按分卷归位批量创建章节并写入梗概；分卷不存在自动创建，卷内已有同名章节则覆盖梗概
- 聊天页同样可勾选启用

两个工具可同时勾选；AI 回答中解析出多种标记块时**逐个询问是否导入**。未选书时会弹选书窗口（含完整新建书籍表单：封面 / 简介 / 分组）。工具协议开放，后续会持续增加新工具。

**长期记忆（书本向量化 / 记忆检索）**

把本书**已写正文**向量化存入本机，写新章节时自动翻出「和本章梗概最相关」的旧正文片段，作为参考资料随提示词一起交给写文模型（向量工具只负责检索，结果不会直接返回给你）。

- 开启方式：设置 → 通用设置 → **长期记忆**；开启后在 AI 侧边栏 / 对话页勾选「记忆检索」
- **向量化工具二选一**：
  - 厂商 Embedding API：填 BaseURL / API Key / 模型，随时可换
  - **本地向量化工具**：内置 llama.cpp（arm64-v8a），需先下载 `BGE small zh v1.5`（约 15MB）与 `BGE reranker base`（约 209MB）两个模型，支持断点续传；两个模型全部就绪后方可启用，向量化与检索全程离线
- **检索链路**：先按余弦粗召回 Top20，再用重排模型精排到目标区块数；本地工具走 BGE reranker，厂商 API 无重排时等价纯余弦
- **记忆检索区块设置**：区块配额 5-20、检索范围偏好（随机匹配 / 最新章节优先 / 最早章节优先），可在此子页配置
- **检索范围与配额**：自动排除「当前正在写的这一章」，且同一章最多取 2 块，避免参考资料全挤在一章
- **向量化进度**：按「全部书籍 / 各分组 / 未分组」查看筛选
- **增量向量化**：正文改动会自动重跑对应章节；切换向量化工具 / 模型会整本重跑（不同工具产出的向量不在同一向量空间）；未重新向量化时会明确提示

### AI 配置

- **供应商管理**：名称、BaseURL、API Key、接口类型（Chat Completions / Responses），支持快捷添加常见供应商
- **模型管理**：从供应商自动拉取可选模型列表，按模型配置温度、最大输出 token
- **思考模式**：每个模型可单独设置是否开启思考/推理，以及思考强度档位（低 / 中 / 高 / 极，默认开启且取最高强度）；按模型自动映射到各后端原生参数（OpenAI / DeepSeek 的 `reasoning_effort`、Claude 的 `thinking.budget_tokens`、千问的 `chat_template_kwargs`、智谱 / 豆包的 `thinking.type` 等），超出模型支持范围时自动夹取到可用最大值；未识别的模型不发送任何思考参数
- **预设提示词**：系统级 prompt 配置
- **上下文不限**：可关闭上下文长度限制

### 使用说明书（内置）

- 首次启动自动在书架上生成一本《炼文炉 · 使用说明书》，按章节覆盖 App 全部功能，与普通书籍一样可阅读 / 导出 / 分享
- 设置 → 通用设置 → **使用说明**：引导你在书架上查看说明书，并提示配置好模型后可把整本说明书交给 AI 提问；也可把说明书导出为 txt 上传到网页版 AI 提问
- 说明书内容随 App 版本自动更新（若已被删除会重新生成一本）

### 其他

- 数据全在本机 Room 数据库，导出走系统分享

## AI 大纲导入格式

「写入大纲工具」使用如下固定格式（复制提示词后 AI 会自动遵循）：

```text
<<<AI_OUTLINE_JSON_V1>>>
{
  "blocks": [
    {
      "type": "标签",
      "name": "显示名称",
      "fields": [
        {"key": "字段名", "value": "字段值"}
      ]
    }
  ]
}
<<<END_AI_OUTLINE_JSON_V1>>>
```

- `type`：所属大类（人设 / 世界观 / 故事线……），无则新建标签
- `name`：条目显示名，同标签下重名自动加序号
- `fields`：条目字段；字段值含引号或换行需按 JSON 规则转义

## AI 章节梗概导入格式

「章节梗概导入工具」使用如下固定格式：

```text
<<<AI_CHAPTER_JSON_V1>>>
{
  "chapters": [
    {
      "volume": "分卷名，没有可写空字符串",
      "chapterName": "章节名",
      "summary": "章节梗概",
      "order": "章节在本卷的序列号"
    }
  ]
}
<<<END_AI_CHAPTER_JSON_V1>>>
```

- `volume`：分卷名；为空则写入第一卷，分卷不存在则自动创建
- `chapterName`：章节名；卷内已有同名章节则打开该章（写入而非新建）
- `summary`：章节梗概；该章已有梗概则覆盖
- `order`：章节在本卷的序列号（新章节按顺序追加）
