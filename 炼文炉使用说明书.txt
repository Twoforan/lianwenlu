# 炼文炉 · 使用说明书

本说明书覆盖炼文炉的全部功能与操作路径。它已经作为一本书内置在书架中，你可以在 AI 对话里把它选中作为「上下文书籍」，直接向 AI 提问本 App 的用法（例如「怎么开启本地向量化」「大纲怎么批量导入」）。

## 一、快速开始

1. 配置 AI：底部导航栏进入「设置」→ 通用设置 → 供应商管理 → 新增供应商，填写 BaseURL 与 API Key，选择接口类型（Chat Completions 或 Responses）；再到模型管理拉取或手动添加模型，设置温度与最大输出 token。
2. 新建书籍：书架页点「新建」，填写书名、简介，选择所属分组（也可现场新建分组）。
3. 建立卷与章节：进入书籍 → 打开目录侧栏 → 新建分卷 / 新建章节，即可开始码字。
4. 唤起 AI：在章节编辑页右侧抽屉里可以直接对话；也可以从底部导航栏的「AI 对话」进入完整会话页。
5. 给 AI 喂上下文：在 AI 对话页勾选书籍、章节或大纲条目，AI 的回答就会基于这些内容。
6. 让 AI 写回大纲：启用「写入大纲工具」后，AI 生成的人设 / 世界观 / 故事线会以工具调用的方式回传，应用自动弹出导入预览，勾选确认后写入大纲库。
7. 让 AI 代笔：在章节编辑页侧边对话抽屉里点「生成梗概」或「生成正文」，AI 会按本章设定产出草稿（见第六章）。

## 二、书架与书籍管理

- 展示模式：列表 / 图墙两种，可在设置或书架工具栏切换。
- 排序：按时间或名称，支持正序 / 倒序。
- 分组：创建分组、把书籍移动分组、按分组筛选；书架顶部筛选栏是胶囊样式，选中分组会高亮，可一键清除筛选。
- 书籍操作：编辑（修改封面、书名、简介、分组、标题前缀）、置顶、预览、分享、复制本书、删除。
- 复制本书：在书籍「更多」菜单里，位于「删除本书」之前。新书是一本空白书（只有默认首卷首章），原书的**大纲会完整复制过去**（分类标签、字段内容与排序位置都保留），封面、简介、分卷 / 章节标题前缀与所属分组也会沿用；新书标题自动追加 （1）（2）… 序号。原书里已**常驻化**的分类标签、自定义分类与各分类的字段模板同样会迁移到新书。
- 批量管理：进入批量模式后可全选 / 取消全选、删除，标题栏显示已选数量，底部操作栏有明确的「取消」按钮退出批量模式。
- 封面：可选本地图片；未选图片时使用纯色封面加书名兜底，底色可自定义。
- 导出：整本合并导出为单个 txt 或 Word（txt 会带上分卷标题）；也可按章节分别导出，文件按分卷子目录组织。
- 分享：单章可生成图片 / txt / Word 分享出去。
- 内置说明书：首次启动会自动生成一本《炼文炉 · 使用说明书》，与普通书籍一样出现在书架上，可以打开阅读、导出，也可以作为 AI 上下文书籍提问。

## 三、分卷与章节

- 标题前缀：书籍可自定义分卷前缀 `第%n卷` 与章节前缀 `第%n章`，其中 `%n` 为阿拉伯数字（1、2、3），`%N` 为中文数字（一、二、三）。
- 目录侧栏：可新建章节 / 分卷，长按删除，拖拽任意排序，支持正序 / 倒序切换；默认展开上次编辑章节所属的分卷，其余收起。
- 长按章节弹出的菜单：可「批量管理」（多选、拖拽排序、批量移动分卷、批量删除、批量合并成章、一键重排章节序号），也可就地修改章节标题，改完自动写回书籍。
- 批量管理的作用范围：只管理**触发它的那一卷**下的章节（未分卷章节单独成组），其它卷的章节不会出现在列表里、也不参与操作；其中「一键重排章节序号」只重排本卷的章节编号，其它卷的标题不受影响。
- 章节内容由三部分组成：标题、梗概、正文。梗概会被 AI 用作检索与上下文注入的依据，务必尽量填写。
- 移动章节：可把章节移动到其它分卷。

## 四、章节编辑

- 即时自动保存，无需手动保存。
- 一键排版：首行缩进两字符，可配置行间距、左右边距、底部边距、排版空行。
- 样式：字号、字体、加粗 / 斜体 / 居中对齐、字体颜色、背景颜色。
- 智能标点：成对标点自动补全，冒号紧随双引号。
- 快速定位：自动记住上次退出时的光标位置，回到该章直接继续。
- 查看菜单：查找替换、全书查找、字数统计、粘贴、全选。
- 工具箱：分享章节（图片 / txt / Word）、人名生成、地名生成、AI 人名 / 地名生成、保持屏幕常亮。
- 阅读模式：进入阅读页后可在样式面板里选择翻页方式（上下滚动 / 左右翻页），并可用开关控制「全屏阅读（隐藏系统栏）」。
- 左右滑动切章：左右翻页模式下，翻到本章末页继续向左滑即进入下一章，在本章首页向右滑则回到上一章，不必再点左右半屏。
- 段距：样式面板里的「段距」控制**自然段与自然段之间**的空行数（0 / 1 / 2 行三档），调整后正文会立即重新排版并重新分页；「行距」控制的是一段之内行与行的距离，两者互不影响。
- 阅读进度：底部常驻页脚显示当前卷内的章节进度（如「第一卷 · 青云志 · 第 1/3 章」）与该卷内的阅读百分比；工具栏「进度」面板可按分卷切换查看，只列出该分卷下的章节，并同时显示全书第几章，可拖动滑块或在卷间切换后一键跳转。
- 右侧抽屉：不离开编辑器即可唤起完整 AI 对话；抽屉头部标题为「AI」，下方一行显示当前所在章节，长按章节名可直接改名（改完同步更新抽屉头部、编辑器标题栏与书本目录）；抽屉底部有「跳转本卷下一章节」按钮——本卷已有下一章时直接跳过去，已到本卷末章则自动在本卷新建一章再跳过去，并保持侧边对话栏打开。抽屉底部快捷按钮行（一屏正好容纳、无需左右滑动）包含「＋本章梗概」「快捷提示词」「梗概 + 发送」「正文 + 发送」「发送」五项，可让 AI 直接产出草稿（见第六章）。

## 五、作品大纲

- 大纲按标签分类组织，内置分类有：故事大纲、人设、世界观、灵感库；分类可自由增删，长按标签可编辑或删除。
- 分类「常驻化」：长按标签弹出的菜单里点「常驻化」可将该分类设为常驻（再次点击取消），已常驻的标签前会显示一枚图钉图标。配合「适配性筛选」（见第六章）使用，可让常驻分类的大纲始终作为首轮上下文；该开关同样作用于「生成正文」时的参考资料。
- 每条大纲 = 显示标签 + 结构化字段（字段名 / 字段值）（说明：每条大纲的首个字段即其「显示标签」，也就是这条大纲的标题；其余字段构成这张「表」的内容）。
- 字段模板按分类记忆：你在某分类下用过的字段名，下次新建同类条目会自动带出来。
- 大纲可以按标签筛选和搜索，方便快速定位。
- 大纲导入规则：同一标签下**名称一致的条目覆盖替换**，新条目**追加到该标签末尾**。
- AI 生成的大纲可通过「写入大纲工具」批量导入：勾选工具后模型会以工具调用回传结构化内容，应用自动弹出导入预览（见第七章）。

## 六、AI 对话

入口有两处：章节编辑页右侧抽屉、底部导航栏的「AI 对话」。

- 流式输出：回答逐字出现；思考过程（reasoning）单独展示，不干扰正文阅读。响应生成中与生成完成使用同一张卡片外壳，只是末尾一行显示「model: 模型名 + 正在生成…」、操作栏放「停止响应」，不会出现生成前后两种样式。
- 按章节断点折叠：会话自动按章节分组，每一组都带章节抬头、可整组收起（含最后一章，导航栏 AI 与编辑器侧边栏一致）。**默认全部收起成块**（含当前章节），收起后显示章节名、「共 N 条对话 · 约 N 字」与一行内容预览；你手动点开 / 收起过的分组会被记住，下次进入沿用上次的效果。长按分组标题里的章节名可直接改名，保存后同步更新到书籍目录；**章节被删除后该分组仍可长按重命名**（章节删除即解除映射，改名只作用于这一组，不写回书籍）。未绑定章节的对话则按「一轮对话」成块，标题显示为「第 X 轮对话」，长按可改本轮名称（只改这里，不会同步到书籍章节）。
- 分组卡片为「头 — 对话 — 尾」结构：展开时底部有一条带 ∧ 的收起条，点卡片头部或底部收起条都能把整块向上收起。
- 消息抬头：用户消息与 AI 回答都不显示时间和「分卷 · 章节名」抬头，只保留正文与操作栏。
- 长对话定位：展开章节编辑页的侧边 AI 时，自动滑动到绑定章节对应的对话分组（不再自动展开，展开与否沿用上次的选择）；导航栏 AI 或未绑定章节的侧边 AI 打开时，自动滑到最后一轮对话的末端。
- 单条消息的小收起：用户消息与 AI 回答的操作栏里各有一个「收起 / 展开」图标，只折叠当前这一条（收起后保留一行内容预览），不影响所属章节分组。
- 消息操作：长按选中复制（点别处取消选中）；消息支持编辑重发、删除、回复引用；同一条提问可切换多个回答版本。「重新生成」产生的多个版本里，只有**当前生效的那一版**会进入后续请求的历史，废弃候选不会堆积进上下文（避免提示词 token 膨胀）。
- 会话列表与换绑书籍：点顶部「会话」打开会话列表，可按「跟书 / 跟章节 / 未绑定」筛选，也可按分组与书籍筛选、搜索；长按某个会话可**修改名称**或**切换绑定书籍**。切换绑定时弹窗提供「历史对话」「历史预设」两个勾选项 —— 勾「历史对话」把原有对话历史带入新书上下文，勾「历史预设」把此前导入的大纲与章节梗概保留进新书预设；两项全选即整段搬运到新书，并自动解除原有的章节映射。
- 功能栏「查看日志」：弹窗标题为「提交日志」，以可折叠的三级结构展示每次请求到底发了什么（预设日志 / 上下文日志 / 本轮提示词日志），末段「工具日志」记录本轮实际下发的工具名与模型原始响应摘要（含工具调用及其参数）。排查「模型没调用工具」时先看这里。其中「预设提示词」显示的是模型配置里实际生效的系统提示词。
- 功能栏「查看本轮提示词」：只回显本轮实际发送给 AI 的内容（本章梗概、检索片段、新增大纲、用户提示词），不含系统预设、自定义前缀与历史轮次。
- 侧边抽屉头部：标题为「AI」，下方一行显示当前所在章节，长按章节名可直接改名，改完同步更新抽屉头部、编辑器标题栏与书本目录三处。顶栏右侧依次为模型选择、预览、新开对话、关闭；点「预览」（眼睛图标）可直接进入当前章节的阅读预览，与编辑器顶栏的预览入口一致。
- 写入当前章节（仅右侧抽屉）：AI 回答的操作项里有「写入当前章节」，一点即可把这条回答覆盖写入当前章节的正文并自动一键排版；本章已有正文时会先弹窗确认，同意后才覆盖，不同意则不写入。若该回答是单独生成的梗概，操作项里则是「写入梗概」。
- 输入框：导航栏 AI 聊天页的输入框内保留圆形发送按钮；编辑器侧边抽屉的输入框不设发送按钮，发送由底部快捷按钮行的「发送」承担。
- 常用提示词库：标题 + 内容，一键插入输入框；可在设置里维护。
- 文件清单：随会话生成，可复制，方便把内容粘贴到网页版继续讨论。
- 缓存命中率：会话里显示每轮的 cached tokens / prompt tokens，直观看到省了多少。

### 上下文选择

- 「上下文」「大纲」两枚按钮**只保留文字、不带展开箭头**，有条目被选中时按钮以淡紫底高亮；四个按钮（上下文 / 大纲 / 记忆检索 / 下一章）按权重分配宽度，一屏正好容纳，无需左右滑动。
- 「上下文」展开面板：白卡外观，头部是圆形图标 + 「选择上下文」+「已选 N 章」，下面是「全选 / 梗概 / 正文」三个筛选药丸，再下面依次是「章节 / 梗概 / 正文」三列表头与列表；分卷行带展开箭头、勾选框、卷名与「已选 / 总数」，章节行以圆点缩进。
- 「大纲」展开面板：白卡外观，头部是圆形图标 + 「选择大纲」+「已选 N 项」，下面是「全选 / 全部大纲 / 常驻大纲 / 普通大纲」筛选药丸，再下面是分类分组行（展开箭头 + 勾选框 + 分类名 + 已选计数）与条目行。
- 书籍：单选，支持分组筛选与搜索，可在弹窗里现场新建书籍（自动选中新建的那本）。
- 章节（逐章独立勾选）：面板顶部有「全选 / 梗概 / 正文」三个按钮 —— 点「全选」一键全选或取消全部章节，点「梗概」一键全选或取消所有章节的梗概，点「正文」一键全选或取消所有章节的正文；下方列表按「章节 / 梗概 / 正文」三列复选框展示，可单独勾选任意分卷或任意章节的梗概与正文，精确控制注入粒度、省 token。
- 大纲条目：按标签筛选 + 搜索；「全选」旁可按「全部大纲 / 常驻大纲 / 普通大纲」筛选，全选按当前筛选范围生效。
- 上下文绑定：统一按「跟书走」，AI 上下文一律绑定整本书（不再有跟书走 / 跟章节走的切换）。

### 生成梗概与生成正文（章节编辑页侧边抽屉）

「生成梗概」「生成正文」是章节编辑页侧边 AI 抽屉底部快捷按钮行里的两个入口（与「＋本章梗概」「快捷提示词」「发送」同排，共五项，一屏正好容纳、无需左右滑动）。两者都按「设置 → AI工具 → 生成设置」里的配置工作。

- 生成梗概：按本章上下文（本会话前缀里的设定 / 资料）与（可选）你指定的大纲条目撰写本章梗概，生成结果**只输出梗概正文这一整段文字**，不会附带核心事件清单、步骤说明、字数统计等多余内容。单独点它时，聊天区会显示这次生成对应的**用户提示词与 AI 回复**，该回复的操作项里带「**写入梗概**」图标，点一下即可把这条梗概写回本章梗概栏。未在章节编辑页使用（没有绑定章节）时按钮不可用。
- 生成正文：按本章梗概、会话前缀里的大纲设定与（可选）记忆检索片段撰写正文；结果作为一条普通 AI 回答进入当前会话（对话里会留下一条标注「生成正文」的请求和对应的回答），由你在该回答的操作项里点「写入当前章节」决定是否落笔 —— **不会自动写入正文**。写入时会覆盖整章正文并自动一键排版，本章已有正文时会先弹窗确认。**生成正文且同时生成梗概时，梗概内容保持隐形**，不占用对话展示。
- 与会话共享前缀与缓存：生成请求和普通聊天复用同一段「模型预设 + 自定义前缀 + 工具块 + 参考资料前缀」，供应商侧的前缀缓存可以在聊天与生成之间共享命中。开启「生成工具携带本会话历史消息」（**设置 → AI工具 → 生成设置** 页最下方的开关，默认关闭）后，历史对话会以「**前情提要**」参考资料块的形式随请求发出，**不再作为对话轮次**，因此 AI 不会把上一章的成品误当成自己正在续写的内容；该块会**按章节分段，并在每段前标注章节名**（如「第3章」「第4章X」），格式为「章节名 → `用户：…` / `助手：…`」，生成梗概与生成正文两条路径一致；生成指令还会点明「现在撰写的是『本章标题』」。
- 本章没有梗概时：若关闭了「生成正文的同时生成梗概」，会先提示先填写本章梗概（或到设置里开启「同时生成梗概」）。
- 输入框里的文字：你在提示词输入框里写的内容会作为生成请求的**最后一条用户消息**一起发出，因此其中写的情节要求会被当作提示词生效；**提示词随请求发出后输入框会自动清空**，避免重复生成。开启「同时生成梗概」时，同一段输入会被发送两次（一次给梗概子调用、一次给正文）。
- 弹窗一次性弹干净：点「生成正文」时，所有需要你决策的弹窗（先「选择大纲」，再「是否启用记忆检索」）会在**进入执行前按固定顺序依次弹完**，执行阶段不再弹任何需要输入的选择框；**任一弹窗点「取消」（或关闭弹窗）都会整体终止**，不会发出任何生成请求。两个弹窗都已按新设计稿重排为全宽圆角卡片：「选择大纲」带搜索框、分类药丸、全选与条目列表（含分类标签与摘要），底部「取消 / 确定」；「是否启用记忆检索」带圆形放大镜图标与淡紫说明块（本次检索词摘要 + 开启 / 关闭说明），底部「关闭 / 开启」。
- 生成进行中：工具栏正上方会浮出一枚「生成中」冒泡小药丸（带转圈图标），底部操作栏同时给出「停止」按钮，可随时中止。记忆检索进行中同位置显示「搜索中」。
- 生成过程实时回显：点「生成梗概」或「生成正文」后，模型的**逐步输出会实时显示在对话里本轮回答的位置**（与完成态一致的卡片外壳，末尾一行显示「model: 模型名 + 正在生成…」，操作栏为「停止响应」），并自动展开本轮所在的对话分组、跟随滚动到底部；生成完成后同一位置换成正式回答。开启「生成正文的同时生成梗概」时**只回显正文的输出**，梗概子调用保持静默；回显内容以最终落库的文本为准（超出字数上限会截断）。
- 梗概子调用失败三选一：开启「同时生成梗概」时，如果梗概生成失败，会弹出「重试梗概 / 使用已有梗概 / 取消」让你明确选择，避免出现「梗概为空却已写出正文」。
- 生成过程中可点「停止生成」随时中止。正文字数超出上限会自动截断到最后一个完整句子并提示；低于下限只提示、不自动重试。

### 生成设置（设置 → AI工具 → 生成设置）

- 字数区间：梗概 0–500 字、正文 0–6000 字，各用一根**双滑块**调节；把下限拉到 0 表示不约束下限。超出上限时自动截断到最后一个完整句子并提示；低于下限只提示、不重试。字数只写进提示词做硬约束，请求的 max_tokens 由模型自身配置决定。
- 「限定梗概范围」开关（默认关闭）：开启后点「生成梗概」会先弹出**大纲条目多选**（可按分类筛选、全选 / 取消），只按选中的设定生成；若某个标签已在会话上下文中，只写「参见大纲『X』」而不再重复提交其内容。
- 「记忆检索」三态（开启 / 关闭 / 询问，**默认询问**）：生成正文前是否按本章梗概检索本书已写正文片段作为参考资料；检索段数沿用长期记忆里的「区块配额」设置。询问模式下点「取消」会终止整个生成流程。若长期记忆里开启了「记忆检索是否限定范围」，确认开启检索后会**再弹一次检索范围选择**（只列出已向量化的章节与分卷）。
- 「生成正文的同时生成梗概」开关（默认关闭）：开启后先生成梗概并静默写入本章梗概，再据此生成正文；关闭时若本章没有梗概会提示先填写。
- 「**生成工具携带本会话历史消息**」开关（默认关闭，位于本页最下方）：控制「生成梗概 / 生成正文」的请求**是否带上本会话的历史对话**，也就是「续写时 AI 能不能看到前面几章写了什么」。
  - **开启**：本会话的历史对话会以「【前情提要】」参考资料块随请求发出（按章节分段，每段前标注章节名，格式为「第3章 → `用户：…` / `助手：…`」；卷切换处会带上卷名，如「第二卷：第4章」，避免不同卷的同号章节混淆），生成时会延续前文的人物、设定与剧情走向；因为请求从第二轮起变长，供应商侧的前缀缓存**命中量随轮次累积**（写得越多、省得越多）。
  - **关闭**（默认）：生成请求只复用与普通聊天逐字一致的前置块（模型预设 + 自定义前缀 + 工具块 + 参考资料前缀），请求长度恒定、缓存命中长度也恒定；生成内容只依据本章设定、本章梗概与（可选的）检索片段，不看本会话历史。
  - 两种模式下历史都**只作为参考资料注入**，不会作为对话轮次发出（详见上一节「与会话共享前缀与缓存」）；前情提要块插在共享前缀之后、生成指令之前，因此聊天与生成共享的前缀缓存**不受影响**。

### 省 token 与提示词缓存

- 首轮注入：上下文一律按「跟书走」，大纲等大块上下文只在首轮注入，后续轮次复用，显著提高供应商侧的 prompt cache 命中率。
- 前缀稳定：多轮之间上下文前缀保持稳定，最大化缓存命中。
- 已适配 GPT、Claude 的缓存机制。

### 前缀词管理

- 位置：设置 → 通用设置 → 前缀词管理。
- 五个选项：上下文前缀化（默认开启）、大纲前缀化（默认开启）、适配性筛选（默认关闭）、自定义纯文本前缀、首轮全选大纲与章节（从「通用设置」移入本页）。
- 首轮全选大纲与章节：新建「跟书」会话时默认勾选全部大纲与章节（梗概全选、正文不选）。这些内容在第一轮发送时冻结进会话前缀，**首轮发送完成后勾选会自动取消**，第二轮起默认不勾选；之后再勾选只会作为「新增参考资料」追加，不会重复提交已进前缀的内容。对应的前缀化开关关闭时不清空（勾选内容需要每轮实时注入）。
- 适配性筛选：开启后，首轮「全选大纲」改为只全选「常驻化」分类下的全部内容；之后每轮发送提示词时，自动用本章梗概匹配「非常驻化」分类下各条目的显示标签，命中的条目把其下完整字段（表）作为「新增大纲资料」，在检索片段之后、提示词之前提交给 AI。已提交过的条目不重复提交，只有新命中或新增的大纲才追加。关闭则维持原样：首轮全选全部大纲（不论是否常驻化）。
- 适配性筛选的作用范围：该开关此前只影响普通聊天发送；现在开启后，**「生成正文」时同样生效** —— 会用本章梗概匹配非常驻化分类下各条目的显示标签，命中的条目以「新增大纲资料」并入本次正文的参考资料。触发条件只需该开关本身开启。
- 前缀只增不减：取消勾选已加入的章节 / 大纲不会删除已有前缀内容；只有对应内容发生变更时才更新该条目；新增勾选的内容追加到前缀末尾。
- 更新时机：只有你重新勾选对应内容时才会对比更新，持续勾选的内容不再刷新，保证前缀稳定。
- 存储范围：前缀只存在于当前会话，新建对话自动生成空前缀，删除会话会同步删除对应前缀。

## 七、AI 工具（可插拔）

位置：设置 → 通用设置 → AI 工具。工具卡片**默认全部收起**，点卡片标题才展开对应配置。目前内置「写入大纲工具」「批量写入章节梗概」两个可同时启用的工具，下方另有「生成设置」子页。

「写入大纲工具」

- 复制工具定义：一键复制该工具的 JSON Schema 定义（工具名、说明、参数结构）与旧版标记格式的兼容说明，粘贴给任何支持自定义工具的 AI 即可让它按规范回传。
- 粘贴导入大纲：粘贴含 `<<<AI_OUTLINE_JSON_V1>>>` 标记的文本会直接解析；粘贴自由文本（不含标记）会调用当前模型自动提取成结构化数据后再写入。
- 在 AI 聊天页勾选该工具后，AI 会在合适的时候通过**工具调用**把结构化的大纲项交给应用（回答本身仍是自然语言）。应用会自动弹出导入预览：可逐条勾选、切换目标书籍（可现场新建书籍 / 分组），确认后入库。`type` 标签不存在会新建；同标签下名称一致的条目会被覆盖（预览里用红字标出「将覆盖同名条目」）。

「批量写入章节梗概」

- 复制工具定义：一键复制 `import_chapters` 工具的定义与旧版 `<<<AI_CHAPTER_JSON_V1>>>` 标记说明。
- 粘贴导入章节梗概：粘贴含标记的文本会直接解析；粘贴自由文本会调用当前模型自动提取后再写入。按分卷归位批量创建章节并写入梗概；分卷不存在会自动创建，卷内已有同名章节则覆盖其梗概。
- 聊天页同样可勾选启用，工具被调用时同样弹出导入预览。

「生成设置」

- 入口：设置 → AI工具 → 生成设置（点进去在本页就地打开，返回即回到 AI 工具页）。页面已按新设计稿重排（圆角卡片 + 圆形图标徽标 + 淡紫滑块与单选样式）。
- 集中配置「生成梗概」「生成正文」两类生成的参数：字数区间、「限定梗概范围」、「记忆检索」三态、「生成正文的同时生成梗概」。各项含义见第六章「生成设置」。

说明：

- 工具走的是主流接口的**原生工具调用**（Chat Completions / Responses / Anthropic 三种接口均已适配，流式与一次性返回都支持），不再靠提示词里强制输出标记，因此回答可以自然书写、结构化数据单独回传。
- 旧版 `<<<AI_OUTLINE_JSON_V1>>>` / `<<<AI_CHAPTER_JSON_V1>>>` 标记仍然兼容，粘贴导入两个入口都支持。
- 若当前模型不支持工具调用（带 tools 的请求被拒绝）：请求会自动重试一次不带 tools 的版本，回答操作栏会多出「导入」按钮，点它可用当前模型把该回答二次解析后再导入。
- 部分供应商（含部分 DeepSeek 兼容接口）会把工具调用写进回答正文，而不是标准的 `tool_calls`（常见形式如 `<function=import_chapters>{...}</function>`、`[{"name":...,"arguments":...}]`）。应用会从正文里识别这些语法并还原成工具调用，照常弹出导入预览，同时把这段语法从回答正文中剔除；实在解析不出来时，回答操作栏会明确提示「模型把工具调用写成了正文且没能解析，可在回答上点「导入」手动导入」，不会再静默失败。
- 手动导入会按回答内容判定类型：只含章节特征（如「第 N 章 + 梗概」）时自动改按「批量写入章节梗概」解析，绝不会写成大纲条目；同一条回答里既有大纲设定（人设 / 世界观）又有章节梗概时，两部分分别解析、分别入队确认。
- 「生成正文 / 生成梗概」与侧边 AI 抽屉不携带工具定义，导航栏 AI 未勾选工具时也不会出现「导入」按钮。
- 两个工具可同时勾选；一次回答里解析出多组内容时会逐个弹窗确认。未选书时会弹出选书窗口（含完整新建书籍表单）。工具协议是开放的，后续会持续增加新工具。

## 八、AI 配置

- 供应商管理：名称、BaseURL、API Key、接口类型（Chat Completions / Responses），支持快捷添加常见供应商。
- 模型管理：从供应商自动拉取可选模型列表，也可手动添加；每个模型可单独配置温度、最大输出 token。
- 思考模式：每个模型可单独设置是否开启思考/推理，默认开启并取最高强度；开启时可调思考强度（低、中、高、极，由低到高）。关闭后不再向模型发送思考参数，模型直接作答。所选强度超出该模型支持范围时会自动取该模型可用的最大值（例如 o 系最高只到「高」，选「极」会取「高」）；不在支持列表内的模型不会收到任何思考参数，行为与旧版本一致。DeepSeek V4.1-Flash / V4-Pro 已适配（走 reasoning_effort 的 low / high / max，关闭时发 none）。
- 预设提示词：配置系统级 prompt。
- 上下文不限：可关闭上下文长度限制。
- 测试模型：配置供应商后可测试连通性；未填 API Key、BaseURL 缺失或格式错误都会给出明确中文提示。
- 模型显示：对话栏里的模型名过长会截断显示，选择弹窗里显示完整名称（含备注与供应商）。

## 九、长期记忆（书本向量化与记忆检索）

长期记忆把本书已写的正文向量化存入本机，写新章节时自动检索出与本章梗概最相关的旧正文片段，作为参考资料随提示词一起提交给写文模型。注意：向量化工具只负责检索，它的结果不会直接展示给你，最终回答仍由写文模型生成。

### 开启步骤

1. 设置 → 通用设置 → 长期记忆，打开长期记忆总开关。
2. 选择向量化工具（二选一，互斥）：
   - 厂商 Embedding API：填写 BaseURL、API Key、模型名，三个都填好才算配置就绪。
   - 本地向量化工具：需先下载两个模型 —— `BGE small zh v1.5`（约 15MB）与 `BGE reranker base`（约 209MB）。未下载时开启会提示先下载；下载支持断点续传；两个模型全部就绪后才允许启用。启用后所有向量化与检索请求都改由本地模型处理，全程离线。
3. 在 AI 侧边栏、或导航栏 AI 对话页勾选「记忆检索」按钮。
4. （可选）开启「记忆检索是否限定范围」后，每次勾选「记忆检索」都会先弹出**检索范围选择**：可全选全部章节、按分卷整卷勾选，或只选单个章节；范围弹窗只列出**已向量化**的章节与分卷。关闭时检索覆盖全书章节。
5. 发送消息时，系统把「本章梗概」提交给向量化工具生成向量，在本书已写正文中检索出参考资料，连同提示词一起发送给写文模型。

> 本书从未向量化时，勾选「记忆检索」会先弹窗询问是否向量化全书；确认后先完成向量化，再（如开启了限定范围）弹出检索范围选择，最后才勾选生效。

### 检索规则

- 检索链路：先用余弦相似度粗召回 Top20，再用重排模型精排到目标区块数。本地工具走 BGE reranker；厂商 API 没有重排时等价于纯余弦排序。
- 排除当前章：正在写的那一章不会进入候选池（它已经在当前上下文里）。
- 每章配额：同一章最多取 2 块，避免参考资料全挤在一章。
- 区块配额与范围偏好：设置 → 通用设置 → 长期记忆 → 记忆检索区块设置，可配置区块配额（5-20）与检索范围偏好（随机匹配 / 最新章节优先 / 最早章节优先）。范围偏好是「软加权」而非硬性限定。
- 限定检索范围：设置 → 通用设置 → 长期记忆 → 开启「记忆检索是否限定范围」（默认关闭）后，每次勾选记忆检索都会先选章节范围；范围弹窗只列已向量化章节，未向量化的章节不会出现。生成正文时若开启了该开关，也会在确认启用记忆检索后再弹同样的范围选择。
- 片段去重：与「适配性筛选」的大纲资料采用同一套去重机制 —— 已在本会话提交过的检索片段不再重复注入（去重键是片段文本的短哈希，存在会话前缀里、只增不减）；换绑书籍时会重置这些去重键。

### 向量化与进度

- 增量向量化：正文改动后只会重跑有变化的章节；未变化的章节会跳过。
- 删除章节同步清理向量：删除章节（含批量删除、合并章节、删除整本书）时会**一并清除该章节的全部向量块**，避免已删内容仍被检索召回、污染新文参考；检索阶段也会按「现存章节」过滤，即使有孤儿向量残留也不会再进入参考资料。
- 换源整本重跑：切换向量化工具或更换模型后，会整本重新向量化一次 —— 不同工具 / 模型产出的向量不在同一向量空间，必须重跑，否则检索不到结果。若库里还有旧源向量且未重新向量化，检索失败时会提示「本书向量由其它向量化工具生成，请先重新向量化后再使用记忆检索」。
- 进度查看：向量化进度页可按「全部书籍 / 各个分组 / 未分组」筛选查看对应书籍的进度。
- 重新向量化 / 更新向量化：进度页每本书右侧有两个按钮。左侧 **重新向量化** 先删除该书已有全部向量，再按当前向量源从头重建，适用于换了向量模型 / 供应商或怀疑旧向量已脏；右侧 **更新向量化** 只对比章节内容，仅重跑有更新的章节，未变化的自动跳过。两者点击后都会先弹窗确认。
- 逐章查看与单独重建：在进度页**点击某本书**进入详情页，按分卷展示每章「已向量化 / 未向量化」；点击任意章节即可**只重建这一章**（先删除该章原有向量再重建），无需整本重跑。
- 自动静默：发送消息触发的自动向量化是静默进行的，不会打断你。
- 前置校验：未配置好向量化工具时，两处「记忆检索」按钮不可用；本章没有梗概时勾选会提示「本章暂无梗概，无法进行记忆检索匹配」。

## 十、设置与个性化

- 设置页默认进入「通用设置」；从 AI 工具、前缀词管理、长期记忆等子页面返回时，也会回到通用设置页。
- 通用设置页入口：使用说明、前缀词管理、数据备份、数据恢复、AI工具、长期记忆（书本向量化）、检查更新。
- 夜间模式、响应式布局，适配各种手机小窗 / 分屏模式。
- 排序与展示：排序方式、正序 / 倒序、列表 / 图墙。
- **数据备份**：设置 → 通用设置 → 数据备份，可把本机**全部书籍的大纲、正文与梗概**（含分卷、章节顺序、大纲分类标签与字段模板）打包成一个 zip。弹窗里可选「保存到文件」用系统文件选择器存到本机或网盘，也可选「分享」发到聊天工具 / 网盘等其它应用。备份不含模型配置、会话记录与向量数据。
- **数据恢复**：设置 → 通用设置 → 数据恢复，选择本应用生成的备份 zip。文件会先校验标识与格式，符合规则才自动恢复；**书名与书架上现有书籍重合时**会弹窗列出重名书籍，选「覆盖」用备份内容整本替换，选「跳过」保留现有书籍、只恢复其它书。不重合的书籍直接作为新书加入书架。恢复过程在同一事务内完成，中途失败不会留下半本书。

## 十一、常见问题

- 为什么「记忆检索」按钮是灰的？—— 未配置向量化工具（或本地模型未下载完）。先到设置 → 通用设置 → 长期记忆里配置厂商 API（BaseURL / API Key / 模型都要填），或下载并启用本地模型。
- 为什么勾了记忆检索却检索不到片段？—— 常见原因是「换过向量化工具 / 模型但还没重新向量化」，此时库里仍是旧源的向量，界面会提示先重新向量化；也可能是本章还没填梗概。
- 换模型后要不要重新向量化？—— 要。系统会在检测到换源时自动整本重跑一次，跑完即可正常检索。
- AI 回答后没有弹出导入窗口？—— 确认在 AI 聊天页勾选了「写入大纲工具 / 批量写入章节梗概」。模型支持工具调用时会自动弹预览；不支持时会自动降级重试，回答操作栏出现「导入」按钮，点它可让当前模型把该回答二次解析后导入。也可以在设置 → AI工具里用「粘贴导入大纲 / 粘贴导入章节梗概」直接粘贴文本（含标记或自由文本均可）；需要让别的 AI 按规范输出时，用「复制工具定义」把定义发给它。
- 导入的章节梗概去哪了？—— 会按分卷归位写入对应书籍；分卷不存在会自动创建，卷内已有同名章节会被打开并覆盖梗概。
- 怎么让 AI 少花 token？—— 在模型设置中，将最大上下文设置成无限，上下文选择里只勾选需要的「梗概」或「正文」来控制注入粒度，并依赖首轮注入与稳定的前缀结构来提高缓存命中率。上下文统一按「跟书走」绑定整本书，不会丢失全书上下文。
- 怎么把书分享给别人？—— 书籍操作里的「分享」可导出整本 txt / Word；单章可用工具箱的「分享章节」生成图片 / txt / Word。
- 卸载或换设备后数据还在吗？—— 数据只存在本机数据库，卸载即丢失。请先到 设置 → 通用设置 → **数据备份** 打包 zip 并保存 / 分享出去；换设备后在新设备上用 **数据恢复** 导入该 zip 即可（书名重合会询问覆盖还是跳过）。
- 在向量化中填写的api是什么？—— 向量化中是特化的embedding api，目前只有特定厂商供应，供应厂商国内有：阿里云百炼 (DashScope)	https://www.alibabacloud.com/zh/product/modelstudio、

   百度千帆	https://cloud.baidu.com/product/wenxinworkshop、
   腾讯混元	https://cloud.tencent.com/product/hunyuan、

   MiniMax	https://platform.minimaxi.com	、

- 我想要简单配置向量化检索怎么办？—— 打开设置-通用-长期记忆，打开本地工具（需要先下载），之后在 AI 对话里按需勾选「记忆检索」即可。
- 为什么检索范围弹窗里看不到某一章？—— 该章还没有向量化。范围弹窗只列已向量化章节，可先到「长期记忆 → 向量化进度」里更新或单独重建该章。
- 本应用的最佳设置是什么？ ——设置-模型与供应商-模型设置上下文数量选无限；上下文选择按需勾选「梗概 / 正文」（上下文统一跟书走，无需额外设置）。
- 点了「生成正文」为什么正文栏没变化？—— 生成结果会作为一条普通 AI 回答出现在侧边对话里（不会自动落笔），需要你点该回答的「写入当前章节」才会写进本章正文；本章已有正文时会先弹窗确认。
- 「生成梗概 / 生成正文」的字数在哪调？—— 设置 → AI工具 → 生成设置，分别有梗概（0–500 字）与正文（0–6000 字）的双滑块；下限拉到 0 表示不约束。
- 「生成正文」怎么控制是否带上本书的旧正文？—— 在生成设置里把「记忆检索」设为开启 / 关闭 / 询问（默认询问，生成前会弹窗问一次）；询问时点「取消」会终止整个生成流程。若还开启了「记忆检索是否限定范围」，确认开启检索后会再弹一次范围选择（只列已向量化章节）。
- 「生成梗概 / 生成正文」要不要带上本会话的历史对话？—— 到 设置 → AI工具 → 生成设置，打开最下方的「**生成工具携带本会话历史消息**」。开启后新写的章节能延续前几章的剧情（历史以「前情提要」参考资料块注入、按章节标注），且前缀缓存命中量随轮次累积；关闭（默认）则每次生成只看本章设定与梗概，请求长度与缓存命中都恒定。
